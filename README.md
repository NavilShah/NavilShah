I'm Navil Shah, an independent software architect based in Ahmedabad, India. I work on the difficult middle: the point where a new platform, an AI feature or a mobile app has to work with systems that were never designed to talk to each other. I stay involved until it holds after handover.
 
You'll talk to me from the first call to the handover.
 
### What I work on
 
- **ERPNext and Frappe:** custom apps, integrations, portals and upgrades for businesses that run on Frappe.
- **AI-powered software systems:** AI features built into real workflows, with clear limits, logging and a human in charge of the decisions that matter.
- **Integrations between systems:** contracts between systems, written before the code, so each side knows what it sends, what it gets back and what happens when it fails.
- **Web platforms and mobile apps:** full-stack builds from API to screen, designed for the team that has to run them.
### How I work
 
1. Write the design down and get it signed off.
2. Deliver against it, in small pieces you can check.
3. Hand over a running system your team can operate, with the documents to support it.
If we can't write it down, it isn't ready to build, and I'll tell you so.
